# 环境配置清单

本文记录两端运行所需的系统版本、依赖包、环境变量与启动命令，
换机器重装时按此逐项对照即可。所有版本号均为实测值（2026-11-26）。

## 一、硬件

| 角色 | 型号 | CPU | 内存 | 其他 |
|---|---|---|---|---|
| 主机 | 海尔云悦 miniR Pro | Ryzen 7 8745HS（8 核 16 线程） | 32 GB | 网卡 RTL8125（千兆有线） |
| 树莓派 | Raspberry Pi 5 | 4 核 aarch64 | 8 GB | USB 摄像头（UVC，`/dev/video0`） |

摄像头关键参数：YUYV 640x480 上限 20fps、MJPG 上限 10fps、曝光/增益可手动锁定。

## 二、操作系统与 ROS

| 项目 | 主机 | 树莓派 |
|---|---|---|
| 发行版 | Ubuntu 24.04.5 LTS | Ubuntu 24.04.5 LTS |
| 内核 | 6.17.0-14-generic | 6.8.0-1068-raspi |
| 架构 | x86_64 | aarch64 |
| ROS 2 | Jazzy（ros-base `0.11.0-1noble`） | Jazzy（ros-base `0.11.0-1noble`） |
| 安装路径 | `/opt/ros/jazzy` | `/opt/ros/jazzy` |
| 网络管理 | NetworkManager (`nmcli`) | cloud-init + netplan + systemd-networkd（**无 nmcli**） |

两端的 `ROS_DOMAIN_ID` 都是默认值 0，未做修改。

| 包 | 版本 |
|---|---|

## 四、环境变量

| 变量 | 值 | 谁需要 | 作用 |
|---|---|---|---|
| `FASTRTPS_DEFAULT_PROFILES_FILE` | `~/vision_project/config/wire.xml` | 两端所有 ROS 进程 | 把 DDS 的 UDP 锁到有线口，防止视频流跑到 WiFi |
| `ROS_DOMAIN_ID` | `0`（默认） | 两端 | 两端必须一致 |
| `PYTHONPATH` | 由 `source install/setup.bash` 注入 | 主机 | 让 venv 里的 python 找到 `vision_detect` 包 |

`wire.xml` 两端内容只差一个地址：主机 `192.168.10.1`、Pi `192.168.10.2`。
仓库里分别存为 `config/wire-host.xml` / `config/wire-pi.xml`，
部署脚本会按机器复制成 `config/wire.xml`。

## 五、网络

| 机器 | 接口 | IP | 获取方式 |
|---|---|---|---|
| 主机 | `enp1s0` | `192.168.10.1/24` | 静态（NetworkManager，网关留空） |
| 主机 | `wlp2s0` | 热点分配的地址 | DHCP（示例环境：手机热点） |
| 树莓派 | `eth0` | `192.168.10.2/24` | 静态（netplan `50-cloud-init.yaml`，网关留空） |
| 树莓派 | `wlan0` | 热点分配的地址 | DHCP（示例环境：手机热点） |

- 直连网段 `192.168.10.0/24` 不设网关：它只用于 DDS，不参与上网。
- 笔记本 / 手机也连同一个热点时，它们和主机在**同一个网段**，但**没有到
  `192.168.10.0/24` 的路由**，所以从那边访问 Pi 的有线口要走跳板：
  `ssh -J <用户>@<主机热点地址> <用户>@192.168.10.2`
- 浏览器访问检测页面用主机的热点地址：`http://<主机热点地址>:8000`
  （`192.168.10.1:8000` 只有树莓派能访问）

SSH 别名（示例，写在 `~/.ssh/config`）：

```
Host host            # 主机
    HostName <主机热点地址>
    User <你的用户名>

Host pi              # 树莓派（走有线直连口）
    HostName 192.168.10.2
    User <你的用户名>
```

`scripts/deploy.sh` 默认用的就是 `pi` 和 `host` 这两个别名，也可以用
`PI_HOST` / `HOST_HOST` 环境变量覆盖。

## 六、时间同步

端到端延迟依赖两机时钟一致，否则 `lat_ms` 没有意义。

主机 `/etc/chrony/chrony.conf` 追加：

```
allow 192.168.10.0/24
local stratum 8
```

树莓派 `/etc/chrony/chrony.conf` 追加：

```
server 192.168.10.1 iburst prefer
```

测量结果：对时后两机偏差 -85µs 量级。

> 待清理：Pi 上这行被历史脚本重复写入 4 次，不影响功能但属冗余，
> 清理命令见 `config/chrony-pi.conf` 顶部注释。

## 七、启动命令

### 树莓派（开机自启，用户级 systemd）

```bash
# 一次安装（写 unit + enable + linger）
bash ~/vision_project/scripts/pi/install_service.sh

# 日常
systemctl --user start|stop|restart vision-cam
journalctl --user -u vision-cam -f
bash ~/vision_project/scripts/pi/cam_ctl.sh status
```

已安装的 unit：`~/.config/systemd/user/vision-cam.service`
（由 `scripts/pi/vision-cam.service.in` 生成，`@HOME@` 替换为家目录）。

### 主机（桌面双击）

```bash
# 一次生成快捷方式
bash ~/vision_project/scripts/host/install_shortcut.sh

# 之后双击桌面 "YOLO 视觉链路" 即可；命令行等价于
bash ~/vision_project/scripts/host/start_detect.sh
bash ~/vision_project/scripts/host/stop_detect.sh
bash ~/vision_project/scripts/host/status.sh
```

### 手动调试（两端通用）

```bash
cd ~/vision_project/ros2_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash
export FASTRTPS_DEFAULT_PROFILES_FILE=~/vision_project/config/wire.xml

ros2 launch vision_cam cam.launch.py            # 树莓派（先 stop 自启服务）
ros2 launch vision_detect detect.launch.py      # 主机
ros2 run vision_probe probe_node                # 主机：链路探针
```

## 八、已知限制

1. **`vision_detect` 必须用 `~/venv/bin/python3` 运行**。`ros2 run` 会用系统
   python（没有 torch），所以要么用 `start_detect.sh`，要么用
   `launch/detect.launch.py`（它显式指定解释器）。
2. **OpenCV 4.6 的 dnn 不能跑 YOLOv8 ONNX**（实测两处断言失败），
   所以推理留在 Python；详见 `docs/设计说明.md` 第三节。
3. 树莓派 `sudo` 需要密码，因此开机自启用的是**用户级** systemd + linger，
   不涉及 `/etc`。若要改成系统级，把 unit 放到 `/etc/systemd/system/` 并补
   `User=abc` 即可。
