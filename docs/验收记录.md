# 验收记录

验收日期：2026-11-26　环境：Ubuntu 24.04.5 / ROS 2 Jazzy / 有线千兆直连
测试时室内开灯，画面 42~43 KB/帧（夜间同场景约 37 KB/帧，属正常波动）。

## 一、C++ 链路（当前版本）

### 1. 采集与传输（vision_cam → vision_probe）

```
平均帧率    20.0 fps
平均带宽    7.0 Mbps
平均帧大小  42.9 KB
帧间隔      p50 51.8 / p95 52.2 / p99 52.4 ms
端到端延迟  p50 -0.2 ms  (含两机时钟偏差，已对时)
卡顿次数    0  (>200ms 的间隔)
```

15 秒长测：19.6 fps / 6.9 Mbps / 43.1 KB / 卡顿 1 次（启动瞬间）。
帧间隔 p99 与 p50 只差 0.6ms —— 说明链路没有抖动，也不存在排队。

> 延迟出现小负值（-0.2ms）是正常的：两台机器的时钟经 chrony 同步后仍有
> 亚毫秒级残差。绝对值 <1ms，可认为就是"网络 + 编码"的真实开销下限。

### 2. 推理与网页推流（vision_detect）

| 指标 | 实测 |
|---|---|
| 推流帧率 | 19.8 fps |
| 推理耗时 | 14.4 ~ 21.1 ms（yolov8n CPU，均值约 17.6ms） |
| 端到端延迟 | 18.1 ~ 23.5 ms（Pi 采集 → 浏览器收到） |
| 单帧消息 | 36.4 ~ 79.1 KB（4B 头长 + 184~279B JSON + JPEG） |
| JPEG 完整性 | SOI `FF D8` / EOI `FF D9` 全部通过 |

WebSocket 握手：独立用 `hashlib` 复算 `Sec-WebSocket-Accept`，与服务器返回一致。

### 3. 与 Python 版本对比

| 指标 | Python 版（阶段 4/6） | C++ 版（本次） | 结论 |
|---|---|---|---|
| 出流帧率 | 19.9 fps | 20.0 fps | 持平 |
| 带宽 | 6.1 Mbps（夜间） | 7.0 Mbps（白天） | 光照差异，非退化 |
| 帧间隔 p95 | 54.5 ms | 52.2 ms | 略优 |
| 链路延迟 | p50 3.6 ms | p50 -0.2 ms | 更优（去掉了定时器节拍） |
| 端到端延迟 | 24.6 ms | 18.1~23.5 ms | 略优 |
| Pi 端进程数 | 1（Python） | 1（C++） | 相同 |
| Pi 端常驻内存 | 未单独测量 | 22.9 MB（systemd 统计） | 仅记录当前值 |
| Pi 端依赖 | python3 + cv2 + numpy | 仅 libopencv | 少一层解释器与 numpy 中转 |

结论：**功能等价，性能不退化，资源占用更省**。

## 二、开机自启验收（树莓派）

```
$ systemctl --user is-enabled vision-cam
enabled
$ systemctl --user is-active vision-cam
active
$ loginctl show-user abc -p Linger --value
yes
```

服务启动后 journal 持续输出 `19.6 fps / 42.9 KB/帧`，主机侧探针同时收到 20.0 fps，
说明服务化之后链路照常工作，`ExecStart` 里的 `exec` 也确实让 cam_node 成了主进程
（`Main PID: cam_node`，而不是 bash）。

## 三、桌面快捷方式验收（主机）

`~/Desktop/YOLO视觉链路.desktop`：

- 权限 `-rwxrwxr-x`（可执行）
- `metadata::trusted = true`（GNOME 认可为可信启动器）
- `Exec=~/vision_project/scripts/host/start_detect.sh`

冷启动实测：脚本退出码 0，用时 1.8s，`/health` 的 `frames` 从 1 增长到 30，
浏览器可正常出画面。重复双击不会起第二个进程（会直接开浏览器）。

## 五、复现方式

```bash
# 1) 主机：看链路质量
cd ~/vision_project/ros2_ws && source install/setup.bash
export FASTRTPS_DEFAULT_PROFILES_FILE=~/vision_project/config/wire.xml
./install/vision_probe/lib/vision_probe/probe_node --ros-args -p seconds:=15.0

# 2) 主机：校验网页协议（握手 + 帧完整性）
python3 ~/vision_project/scripts/tests/ws_check.py 127.0.0.1 8000 3

# 3) 树莓派：确认自启服务
bash ~/vision_project/scripts/pi/cam_ctl.sh status
```
